# Project brief

## Objective

Create a modern, static Salesforce Developer and Administrator portfolio that helps recruiters and hiring teams quickly understand Jeremy Shull's positioning, capabilities, project evidence, certifications, and contact options.

## Primary audience

- Recruiters screening Salesforce candidates
- Salesforce hiring managers and consultancies
- Organizations hiring CRM administrators, developers, analysts, or support engineers

## Primary user journey

1. Understand Jeremy's Salesforce positioning.
2. Review the strongest project evidence.
3. Open a relevant case study.
4. Assess the business problem, solution, architecture, technology, and learning.
5. Review verified skills and certifications.
6. Download the resume or use an approved contact method.

## Product principles

- Capability before biography depth
- Project evidence before decoration
- Business problems before technology lists
- Clear, factual, recruiter-friendly writing
- Accessible and resilient static delivery
- No invented claims or missing-content theater

## Initial project scope

The content system supports Case Intake and SLA Automation, Slack Contact Quick Action, Weather Lightning Web Component, and Job Application Tracker. Homepage summaries and supporting evidence are published only from verified content; deeper case-study presentation remains assigned to Phase 4.

## Current scope

Phases 0 through 6 are complete: project initialization, design foundation, typed content architecture, the recruiter-first homepage, the published project index and case-study system, supporting routes, restrained visual polish, selective Phosphor icon use, generated project title cards for list surfaces, and the pre-launch accessibility, responsive, performance, security, and SEO reviews. Production deployment remains assigned to Phase 7 after the final Vercel origin is known.
